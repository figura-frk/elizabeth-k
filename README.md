# Сайт Елизаветы Кистень

Статический сайт: чистые HTML, CSS и одна картинка. Никаких сборок, зависимостей
и платформ — файлы кладутся на хостинг как есть и сразу работают.

## Структура

```
index.html          главная
about.html          обо мне
services.html       форматы работы (заготовка)
cases.html          кейсы, сгруппированы по услугам
404.html            страница не найдена
assets/
  styles.css        все стили сайта
  portrait.jpg      портрет
  favicon.svg       иконка вкладки
```

## Что нужно заменить перед публикацией

Открой поиск по всем файлам и замени:

| Что искать    | На что менять                          | Сколько мест |
|---------------|----------------------------------------|--------------|
| `USERNAME`    | твой ник в Telegram и в Instagram      | много        |
| `CHANNEL`     | ссылка на сообщество «Кусаем искусство»| 4            |
| `ANKETA_URL`  | ссылка на анкету (Google Forms и т.п.) | 4            |

В `services.html` пока заглушка — её нужно наполнить.

## Как посмотреть локально

Просто открой `index.html` двойным щелчком. Для более честной проверки:

```bash
python3 -m http.server 8000
```

и зайди на `http://localhost:8000`.

## Как выложить на домен

**Вариант 1 — Netlify (проще всего).** Зайти на netlify.com, перетащить папку
целиком в окно Deploy. Сайт поднимется за секунды. Домен подключается в
Domain settings → Add custom domain.

**Вариант 2 — Vercel.** Загрузить папку или подключить репозиторий на GitHub.
Домен — в настройках проекта.

**Вариант 3 — GitHub Pages.** Создать репозиторий, положить файлы в корень,
включить Pages в Settings → Pages.

**Вариант 4 — обычный хостинг.** Залить всё содержимое папки по FTP в
корневую директорию (обычно `public_html` или `www`).

Во всех случаях HTTPS-сертификат выдаётся автоматически.

## Как редактировать

Всё правится в текстовом редакторе. Тексты — прямо в HTML, оформление —
в `assets/styles.css`.

Основные цвета собраны в начале `styles.css` в блоке `.lk`:

```css
--ink:    #0A0A0A;   /* текст и рамки  */
--paper:  #FAF9F4;   /* фон-бумага     */
--lemon:  #E8FF52;   /* акцент         */
```

Поменяешь там — поменяется на всём сайте.

## Важно про левую колонку

Сайдбар (имя, навигация, фото, контакты) продублирован в каждом HTML-файле.
Если правишь его — правь во всех пяти файлах, иначе разъедется.

Визуально при переходах он не мигает: включён View Transitions API, браузер
анимирует только правую часть. В старых браузерах — обычная перезагрузка,
ничего не ломается.
